# Apna College "Complete C++ DSA Course" — Topic Index (Corrected, 143 Videos / 141 DSA Topics)

## Scope note (read this first)

This folder mirrors the **topic order** of the public YouTube playlist "Complete C++ DSA Course" (channel: Apna College, instructor: Shradha Khapra). There is no tool available to fetch YouTube video transcripts, so **nothing here is transcribed from the actual videos**. The list below is a course **syllabus/topic index** — lecture numbers and titles are public, factual metadata (the same kind of information found in a table of contents) — and every file in this folder is **original content written for this knowledge base**, covering the same standard, industry-wide DSA topics that this (and virtually every other) DSA course teaches. Algorithms and problem names (Kadane's Algorithm, N-Queens, Dijkstra's, etc.) are common technical knowledge, not proprietary to any one course.

**Correction note**: an earlier version of this index was built from a third-party course-tracker site that had duplicate/re-uploaded rows, inflating the count to ~218. The list below was rebuilt from the actual playlist listing (titles + durations + view counts). This gives **143 confirmed, numbered video slots (1–143)** in the pasted playlist snapshot: **141 real DSA topics**, plus **2 non-technical filler videos** kept in the numbering so nothing is silently skipped — **#28** ("How to setup C++ compiler on Mac") and **#52** ("One major update & reaching 1000M views"), both excluded from the DSA topic files but explicitly numbered below so the sequence 1–143 has no unexplained gaps. (A rough web description called this course "144 lectures" — that figure doesn't exactly match this specific snapshot's confirmed count of 143 slots; the channel has also continued uploading new lectures past this snapshot, per the note at the end of Module 9.)

**Language**: Python **and JavaScript** side by side in every file, to match the rest of this knowledge base's convention. The original playlist teaches in C++; each file also carries a short "Rules to remember" section comparing C++ / Python / JavaScript wherever the languages genuinely differ (memory model, typing, standard library tools) — not a line-by-line C++ translation.

**Status legend**: ✅ = file written. Everything else = planned, filled in incrementally, one module at a time, on request.

## How this index gets used

Each ✅ file above is a complete, standalone lesson: simple-English explanation → Brute/Better/Optimal in **both Python and JavaScript** → a "Rules to remember" language-comparison section → a "More Topics Like This" box (harder wording, for extra practice). Planned files get filled in incrementally, one module at a time — ask for the next module (Binary Search, Recursion/Backtracking, Linked Lists, Stacks/Queues, Trees, Graphs, or DP/Greedy) and it gets built out.
